# Dataset policy

This directory is reserved for public, synthetic, or otherwise legally shareable datasets and examples.

Do not commit real industrial operating data, confidential data, proprietary Petrobras data, or operationally sensitive information to this repository.

Unless a dataset-specific license file states otherwise:

- source code in this repository is licensed under the Apache License 2.0;
- datasets should be accompanied by their own license file;
- synthetic or demonstrative datasets may use CC BY 4.0 or CC0, depending on the intended reuse model;
- real industrial datasets must not be added unless there is explicit legal authorization and a clear public release license.

For academic use, please cite the software and, when available, the associated article:

> Safety-Oriented ODEJump Adaptation for Future-Time Anomaly Prediction in Oil and Gas Compressor Systems
